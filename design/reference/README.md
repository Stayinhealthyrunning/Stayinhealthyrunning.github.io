# Loppanalys – designreferenser

Den här mappen är visuell källa för startsidan. Vid framtida designarbete ska referenserna läsas före implementation.

## Hierarki

1. **`approved-mockup.svg` – visuellt facit**
   - Den senast godkända Loppanalys-mockupen.
   - Ska styra helhetskomposition, hero, proportioner, typografisk hierarki, färgtemperatur, loppkort, spacing och den mörka avslutande sektionen.
   - Den är en designreferens, inte en färdig webbskärmdump som ska kopieras pixel för pixel.

2. **`ultravasan-reference.svg` – motivreferens för Ultravasan**
   - Filmstill från användarens Ultravasanfilm.
   - Kärnmotiv: löpare bakifrån på träspång genom myr/tallskog i varmt lågt kvälls-/morgonljus.
   - Ultravasan-kortets bildspråk ska bygga på detta motiv, inte på generisk bergsbild eller orelaterad symbolik.

3. **`gotaleden-reference.svg` – motivreferens för Gotaleden**
   - Filmstill från användarens Gotaledenfilm.
   - Kärnmotiv: smal stig genom ljus, frodig lövskog med stora mattor av vita vitsippor.
   - Gotaleden-kortets bildspråk ska bygga på detta motiv.

## Fastslagen grafisk riktning

- Modern, nordisk och professionell trail-/ultrakänsla.
- Djup skogsgrön som bas, varm orange som återhållsam accent, naturvita/varma ljusa ytor.
- Storslagen natur och löpning ska bära känslan; undvik sportbutikskänsla och klyschiga motivationssymboler.
- Loppanalys ska samtidigt kännas som ett seriöst analysverktyg: kartor, pacing, höjdprofiler, resultat och jämförelser.
- Stiliserad manlig + kvinnlig löpare används som portalens symbol.
- Hero: stor, cinematic och luftig.
- Loppkorten: tydlig bild överst, statusetikett, titel/beskrivning och diskret action.
- Sidan ska vara responsiv och kännas avsiktligt designad även på mobil.

## Viktigt

De här referenserna ska inte ersättas av fri designinterpretation utan uttryckligt beslut. Om implementation och referens divergerar ska implementationen justeras mot referensen.
